# Haven — Real Estate, Reimagined

A responsive real estate landing page concept with GSAP + ScrollTrigger animations and a demo AI concierge.

## Features
- Responsive editorial real-estate design with forest-green, ivory and lime palette.
- GSAP entrance/reveal animations and desktop pinned horizontal storytelling section.
- Sample property cards and favourites.
- Demo AI concierge (rule-based replies; not connected to a live AI model).
- Personal visit and video-call appointment request options.
- International client country, time-zone and preferred-currency fields.
- Date validation and appointment request preview.
- Review cards and a review preview form.
- Property search, bedroom/budget filters and price sorting.

## Run
Open `index.html` in a browser. GSAP and ScrollTrigger are loaded from CDN, and Google Fonts and Unsplash images require internet access.

## Production integrations still required
This is a static demo. Appointment and review forms do not send or store data. Connect a secure backend, server-side validation, email/CRM notifications, calendar availability and confirmation before accepting real bookings. Video appointments need meeting-link creation through a provider such as Google Meet or Zoom. Replace sample testimonials with genuine, permissioned reviews. Currency is a preference field only; prices are not converted live. The AI concierge needs a protected backend/API integration for real AI responses.
